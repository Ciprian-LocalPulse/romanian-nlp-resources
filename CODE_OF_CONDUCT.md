# Cod de conduita

RoOpenNLP este un spatiu pentru colaborare respectuoasa intre cercetatori, studenti, ingineri si voluntari.

Nu acceptam hartuire, discriminare, doxxing, atacuri personale sau publicarea de date personale fara drept de folosire.

Raporteaza problemele printr-un issue privat catre mentinatori sau printr-un canal de contact documentat de organizatie.
