# Roadmap

## Faza 1: Fundatie

- Pipeline-uri de curatare si validare.
- Scheme de adnotare NER, speech si dezinformare.
- Exemple mici si teste.
- Documentatie de licenta si etica.

## Faza 2: Corpusuri comunitare

- Corpus NER modern cu surse licentiate clar.
- Corpus de intrebari-raspunsuri romanesc.
- Set echilibrat pentru dialecte si registru informal.
- Benchmark pentru speech-to-text cu accente regionale.

## Faza 3: Modele

- Baseline-uri transparente.
- Fine-tuning pentru modele romanesti si multilingve.
- Model cards, evaluare pe subseturi si audit de bias.

## Faza 4: Ecosistem

- Publicare pe Hugging Face Datasets.
- Leaderboard romanesc reproductibil.
- Colaborari cu universitati, biblioteci si ONG-uri.
