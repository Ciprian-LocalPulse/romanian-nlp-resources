# Securitate si date sensibile

Nu deschide issue public cu date personale, credentiale, chei API, date medicale sau date financiare private.

Pentru rapoarte de securitate:

1. Descrie problema fara sa publici date reale.
2. Include pasi minimi de reproducere.
3. Propune impactul estimat.

Mentinatorii trebuie sa prioritizeze stergerea datelor sensibile si rotirea credentialelor expuse.
