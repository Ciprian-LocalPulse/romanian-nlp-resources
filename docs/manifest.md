# Manifest RoOpenNLP

RoOpenNLP exista pentru a reduce decalajul dintre limba romana si limbile cu resurse NLP bogate.

## Ce construim

- Date curate si documentate, nu doar fisiere mari.
- Scheme de adnotare transparente.
- Cod reproductibil pentru procesare si evaluare.
- Modele de baza care pot fi auditate.
- Infrastructura gratuita pentru cercetatori din Romania.

## Ce nu facem

- Nu colectam date personale fara drept legal si fara anonimizare.
- Nu redistribuim corpusuri cu licenta incerta.
- Nu prezentam un baseline drept sistem final.
- Nu optimizam doar scoruri agregate ignorand dialecte, minoritati sau erori sociale.
