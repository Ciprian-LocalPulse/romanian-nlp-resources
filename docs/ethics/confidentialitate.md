# Confidentialitate si siguranta

## Principii

- Minimizare: colecteaza doar ce este necesar.
- Anonimizare: elimina date personale inainte de publicare.
- Trasabilitate: pastreaza sursa si licenta.
- Revizuire: datele sensibile trebuie verificate de un reviewer.

## Date personale frecvente

- Nume asociate cu adrese, telefoane, CNP-uri, conturi bancare.
- Date medicale, juridice, financiare.
- Date despre minori.
- Geolocatie precisa.
