# Licente si date

## Separarea cod/date/modele

- Cod: MIT.
- Date: licenta declarata per dataset.
- Modele: licenta compatibila cu licenta datelor de antrenare.

## Acceptam

- Date CC0, CC BY 4.0, CC BY-SA 4.0 sau licente academice clare.
- Date sintetice pentru exemple si teste.
- Scripturi de conversie pentru date gazduite in alta parte.

## Nu acceptam

- Articole copiate integral fara permisiune.
- Transcripturi audio cu consimtamant neclar.
- Date personale brute.
- Date din platforme sociale redistribuite impotriva termenilor platformei.

## Checklist pentru un dataset

- Sursa este documentata.
- Licenta este explicita.
- Pipeline-ul de procesare este reproductibil.
- Exista splituri train/validation/test.
- Exista audit de date personale.
- Exista descriere de bias si limitari.
