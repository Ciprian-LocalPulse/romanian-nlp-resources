# Procesare date

Pipeline recomandat:

1. Import din sursa originala.
2. Validare licenta.
3. Normalizare Unicode si spatii.
4. Detectie date personale.
5. Deduplicare exacta.
6. Deduplicare fuzzy pe subseturi mari.
7. Scor de calitate.
8. Split train/validation/test.
9. Card de dataset.
10. Manifest de release cu hashuri.

Configuratia de baza se afla in `configs/pipeline.yaml`.
