# Dataset sintetic de exemplu

## Rezumat

Set mic, sintetic, folosit exclusiv pentru teste si documentatie.

## Sursa

Creat manual pentru RoOpenNLP. Nu contine persoane reale sau date personale.

## Licenta

MIT pentru exemplele de cod/date sintetice din repository.

## Compozitie

- NER: 2 propozitii.
- Dezinformare: 3 randuri JSONL.
- Speech manifest: 2 randuri fara fisiere audio reale.

## Limitari

Nu trebuie folosit pentru antrenarea unui model real.
